Import Excel
ฐานข้อมูลออนไลน์ (ใช้ร่วมกันทุกหน้า)

วิธีตั้งค่าฐานข้อมูล (ทำครั้งเดียว)
  1. เข้า console.firebase.google.com สร้างโปรเจกต์ แล้วไปที่ Build → Realtime Database → Create Database (เลือก Singapore)
  2. แท็บ Rules วางโค้ดด้านล่าง แล้วกด Publish
  3. คัดลอก URL ของฐานข้อมูลมาวางในช่องด้านบน → ทดสอบ → บันทึก
  4. อัปโหลดไฟล์ HTML นี้ขึ้น GitHub Pages ทุกคนที่เปิดเว็บจะเห็นข้อมูลชุดเดียวกันแบบ Real-time
{
  "rules": {
    ".read": true,
    ".write": true
  }
}

หมายเหตุ: Rules นี้เปิดให้ทุกคนที่รู้ URL อ่าน/เขียนได้ เหมาะกับใช้ภายในทีม ควรสำรองข้อมูลเป็นระยะ (ปุ่ม Export) และระวังโหมด "test mode" ของ Firebase ที่หมดอายุใน 30 วัน
